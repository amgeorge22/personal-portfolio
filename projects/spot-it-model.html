Machine Learning Spot-It! Model

CNNMachine learningPython

For the final project of my machine learning class, I worked with a partner to train a model to recognize the icons on a Spot-It! card in order to play the game Spot-It! The model is trained to recognize the images on a Spot-It! card. In order to play the game, we create a list of the icons the model recognizes on two cards, and then finds the matching items in those lists.

The model we used was a convolutional neural network that took in 64x64 images. To learn more about the model architecture and how we improved it, you can read Model Report in our repository. To learn more about the overall project and play the game, you can check out our README in the repository.

Repository Link: https://github.com/amandalchang/spot_it_cnn
