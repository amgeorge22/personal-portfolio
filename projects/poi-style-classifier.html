Poi Style Classifier

MATLABFourier transformClassification

For the final project of Quantitative Engineering Analysis 3, I worked alongside a team to classify poi spinning styles using accelerometer data and MATLAB's statistics and machine learning toolbox.

Poi is a performance art style and the name of the prop used in this kind of performance. We collected accelerometer data, processed it using Fourier transforms, and created a classifier to distinguish between different poi spinning styles.
