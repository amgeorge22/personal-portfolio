Sudoku Solving with Graph Coloring

Graph theoryPythonColab

The goal of this project was to use graph coloring to solve a sudoku puzzle. Graph coloring is a technique in graph theory that assigns colors to the nodes of a graph so that no two adjacent nodes share the same color. A sudoku puzzle can be represented as a graph where every cell in the grid is a node. Cells that are in the same row, column, or sub-grid are adjacent to each other. We can use graph coloring to color the nodes in this graph, where each color represents a number.
